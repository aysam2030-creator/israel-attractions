## 2024-10-31 - Memoizing React-Leaflet Markers
**Learning:** `react-leaflet` behaves poorly with dynamically generated object properties inside mapping loops. Properties like Leaflet icons (`L.divIcon(...)`), `eventHandlers={{ click: ... }}`, and polyline paths (`pathOptions={{...}}`) are recreated on every render of the parent component, leading to unnecessary and expensive Leaflet-level DOM updates even if values haven't meaningfully changed.
**Action:** Always memoize Leaflet element props. If a marker uses dynamically generated variable components (like an icon depending on its state), maintain an external string-keyed cache (`Map<string, L.DivIcon>`) to avoid recreating the icon object reference. Wrap map children like `<Marker>` in a `React.memo` component, extracting and memoizing `eventHandlers` with `useMemo` so that they possess a stable reference. Provide static `pathOptions` objects outside the render cycle.
