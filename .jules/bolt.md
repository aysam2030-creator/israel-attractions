## 2024-05-24 - React-Leaflet Map Render Thrashing
**Learning:** Leaflet components like `<Marker>` and `<Polyline>` in `react-leaflet` are highly sensitive to inline object creation (like `L.divIcon()` or `pathOptions={{...}}`). Passing these inside a `.map()` loop causes Leaflet to aggressively tear down and recreate native map layers on every React re-render, leading to severe main-thread blocking and DOM thrashing, especially noticeable on mobile devices. Standard React hooks (`useMemo`) cannot be used inside `.map()` loops.
**Action:** Extract list items that wrap Leaflet elements into distinct child components wrapped in `React.memo()`. Cache dynamically generated `L.divIcon` instances using a module-level `Map` rather than recreating them. Hoist static configuration objects (like `pathOptions`) to module-level constants.
