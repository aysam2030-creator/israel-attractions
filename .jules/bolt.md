## 2024-09-24 - Inline functions in Marker eventHandlers cause Leaflet DOM thrashing
**Learning:** Using inline arrow functions in `eventHandlers={{ click: () => setSelected(a) }}` inside `react-leaflet` components like `Marker` causes the event handler to be a new reference on every render. Leaflet has to constantly detach and re-attach event listeners on the DOM nodes, which causes significant thrashing and sluggishness, especially with many markers on a map.
**Action:** Extract the `Marker` into a separate memoized component, or at minimum pass a stable function reference. Passing a stable setState function like `setSelected` isn't enough if the argument `a` needs to be bound. It's better to extract the `Marker` into a subcomponent `MemoizedMarker` using `React.memo` and passing a `useCallback` or the raw `setSelected` dispatcher.
