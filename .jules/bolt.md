## 2023-10-01 - Optimize react-leaflet rendering by memoizing Markers and caching Icons
**Learning:** In React Leaflet, passing inline objects to `eventHandlers` (e.g. `eventHandlers={{ click: () => set(a) }}`) and regenerating `L.divIcon` objects inside mapping loops causes unnecessary DOM updates and re-rendering on every cycle since the object references change.
**Action:** Extract Leaflet elements like `<Marker>` into their own components wrapped in `React.memo()`. Pass stable primitive props (like `isTrip={tripIds.includes(a.id)}` instead of the whole array) and stable state setter functions (like `setSelected` directly) to allow `React.memo` to properly bail out of renders. Additionally, cache dynamically generated objects like `L.divIcon` using an external `Map` based on a composite key.
