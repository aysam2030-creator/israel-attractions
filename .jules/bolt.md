## 2024-07-09 - react-leaflet DOM thrashing via unstable object references
**Learning:** In react-leaflet, passing inline objects to Leaflet components (like `icon={L.divIcon(...)}` or `pathOptions={{...}}`) creates new object instances on every render. This forces Leaflet to completely destroy and recreate map layers on the DOM, causing severe performance bottlenecks, especially with many markers or frequently updating state. Furthermore, caching dynamically generated `L.divIcon` objects that depend on varying arguments (like color and trip step) inside a render loop cannot be easily done with standard hooks without violating the Rules of Hooks inside `.map()`.
**Action:** Always memoize or cache object references passed to react-leaflet components. For dynamically generated objects like `L.divIcon` inside lists, use an external `Map` to cache instances by a stringified key to bypass hook limitations and maintain referential stability.
