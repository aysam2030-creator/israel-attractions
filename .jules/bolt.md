## 2024-06-03 - Cache Leaflet Object References to Prevent DOM Thrashing
**Learning:** In this Vite + React project using `react-leaflet`, passing inline objects or dynamically generating new object references for properties like `icon` (e.g. `L.divIcon` creation on every render), `positions` (e.g. mapping coordinates every render without memoization), or `pathOptions` on components like `Marker` and `Polyline` causes severe DOM thrashing. Leaflet considers the properties changed and re-creates or heavily mutates DOM nodes constantly, leading to serious performance bottlenecks on the map view.
**Action:** Always cache or memoize Leaflet objects (such as `L.divIcon` instances, polyline coordinates arrays via `useMemo`, and options objects via module-level constants) to ensure stable references across renders.
