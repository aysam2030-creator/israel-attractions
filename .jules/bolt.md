## 2024-05-24 - [React Leaflet Marker Optimization]
**Learning:** In `react-leaflet`, passing inline objects or functions to the `eventHandlers` prop (e.g., `eventHandlers={{ click: handler }}`) inside loops creates new object references on every render. This forces the underlying Leaflet components to constantly re-bind events, leading to unnecessary DOM updates and performance degradation, even if the parent map state hasn't changed. Caching `L.divIcon` generation using an external Map (outside the component) avoids unnecessary hook dependencies and prevents expensive DOM recreation for map pins.
**Action:** When rendering lists of complex map markers, always extract the Leaflet element into its own memoized component. Memoize the `eventHandlers` prop inside the extracted component using `useMemo`, and use an external `Map` to cache complex Leaflet icon objects (`L.divIcon`) by a stringified key representing their unique visual state.
