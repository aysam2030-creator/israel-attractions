## 2024-05-15 - [Initial performance investigation]
**Learning:** Found that `makePin` creates new `L.divIcon` instances unconditionally on every render in `App.tsx` (lines 538-542) for every attraction marker in the `react-leaflet` map. This is a common bottleneck causing unnecessary re-creations and potential memory thrashing in React/Leaflet integration. Since map attractions map creates markers dynamically inside `mapAttractions.map`, creating a new instance every render means DOM diffing will be slower.
**Action:** Extract pin creation into a cache (Map) outside the render cycle or use `useMemo`/a module-level cache keyed by `color`, `isTrip`, and `step` to return identical object references for markers unless their visual state actually changes. This will satisfy the objective of improving performance efficiently.
