## 2024-06-25 - React-Leaflet DOM Thrashing via Uncached Objects
**Learning:** In React-Leaflet, passing inline-generated or un-memoized object references (like `L.divIcon` from a helper function, or inline options objects like `pathOptions`) to Leaflet components (like `<Marker>` or `<Polyline>`) causes severe performance bottlenecks. React-Leaflet detects these as prop changes and attempts to continuously destroy and recreate the underlying DOM elements and Leaflet instances, resulting in significant DOM thrashing and CPU spikes.
**Action:** When working with React-Leaflet, always aggressively cache Leaflet configuration objects. Use a global `Map` or `useMemo` for dynamically generated items like `L.divIcon`, and extract static configurations (like `pathOptions` or coordinates) into module-level constants outside the component body. Encapsulating markers into small, `memo`ized components is also critical for long lists of map markers.
