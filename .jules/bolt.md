## 2024-05-24 - React-Leaflet Render Loop Thrashing
**Learning:** In react-leaflet, passing inline objects or functions to Leaflet component props (e.g., `eventHandlers={{ click: handler }}`, `icon={makePin(...)}`, `pathOptions={{ color: "red" }}`) inside a map loop creates new object references on every render. Because Leaflet components internally hook into these object references, doing this causes severe DOM thrashing and completely ruins mapping performance when zooming or panning. Furthermore, `L.divIcon` instantiation is expensive to run on every render.
**Action:** Extract list-rendered Leaflet components (like `<Marker>`) into their own `memo`ized components so that `useMemo` and `useCallback` can be utilized. Cache expensive generic object creations (like `L.divIcon`) using a `Map` external to the component render tree, keyed by arguments. Extract constant objects (like static `pathOptions`) out of the component entirely.
