## 2024-05-24 - React-Leaflet Prop Stability
**Learning:** Passing inline objects (like `pathOptions`) or generating new Leaflet objects on the fly (like `L.divIcon`) during a React render causes react-leaflet to aggressively tear down and recreate DOM elements on the map, leading to severe performance bottlenecks during state updates.
**Action:** Always extract static Leaflet configuration objects to module-level constants and implement caching (like a `Map`) for dynamically generated icons to preserve reference stability across renders.
## 2024-05-24 - Capacitor Gradle Compatibility
**Learning:** If `capacitor-cordova-android-plugins` is dynamically created to satisfy the build process (because it wasn't synced via `npx cap sync`), setting `compileOptions { sourceCompatibility JavaVersion.VERSION_21 }` inside its generated `build.gradle` will cause a "Java compilation initialization error: invalid source release 21" on CI runners that use JDK 17. The Android plugins library should not override the Java version constraint, but rather inherit it or omit it, allowing the main app or the plugin module's default to take precedence based on the JDK running the build.
**Action:** When dynamically generating the missing Cordova plugins `build.gradle`, do not include the `compileOptions` block specifying `JavaVersion.VERSION_21` unless you are certain the environment is running JDK 21. For maximum compatibility with default GitHub Actions using Java 17, omit the `compileOptions` block entirely.
