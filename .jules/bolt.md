## 2025-01-31 - Memoizing Leaflet Map Markers in React
**Learning:** In react-leaflet, passing inline objects or functions to the `eventHandlers` prop (e.g., `eventHandlers={{ click: handler }}`) inside loops creates new object references on every render, which causes React-Leaflet to update the map DOM continuously even if marker props haven't actually changed. Furthermore, generating `L.divIcon` instances inline on every render is incredibly expensive. We cannot simply wrap inline loop variables in `useMemo` due to the Rules of Hooks.
**Action:** Extract the Leaflet `<Marker>` into its own `<MemoizedMarker>` component wrapped in `React.memo()`. This allows `useMemo` to be used for the `eventHandlers` prop internally, and allows primitive prop bailing. For dynamically generated leaf objects like `L.divIcon`, use an external `Map` indexed by a stable stringified key as an in-memory cache to skip recreation across renders.
