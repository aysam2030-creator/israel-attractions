## 2024-07-22 - [React-Leaflet DOM Thrashing]
**Learning:** React-Leaflet components like `Marker` and `Polyline` are highly sensitive to object reference stability for their `icon` and `pathOptions` props respectively. Recreating `L.divIcon` objects or passing inline objects for `pathOptions` directly inside render loops (or functions like `makePin` called during render) will cause Leaflet to tear down and recreate the underlying DOM elements on every React render. This causes severe DOM thrashing and major performance bottlenecks, especially when rendering many markers on a map.
**Action:** Always cache or memoize dynamic Leaflet property objects. Use an external `Map` indexed by a stable string key to cache objects like `L.divIcon` when they depend on dynamic props (like color or indices), and extract static configuration objects (like `pathOptions` for Polylines) to module-level constants.
