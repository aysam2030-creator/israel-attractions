## 2024-07-13 - [Caching react-leaflet marker objects to prevent DOM thrashing]
**Learning:** `react-leaflet` components (like `Marker` and `Polyline`) are highly sensitive to object reference changes in properties like `icon` or `pathOptions`. Passing dynamically generated objects (like `L.divIcon({ ... })` or inline style options `{ color: "..." }`) directly inside the render loop causes severe performance bottlenecks due to DOM thrashing. React hook rules prevent using `useMemo` inside `.map()` loops.
**Action:** When rendering lists of Leaflet items, cache dynamically generated objects (like `L.divIcon` for react-leaflet markers) that depend on variable arguments using an external `Map` (e.g., `new Map<string, L.DivIcon>()`) to store and retrieve instances by a stringified key. Extract static options objects to constants outside the component.
