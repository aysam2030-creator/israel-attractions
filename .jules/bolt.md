## 2024-05-18 - React-Leaflet Map DOM Thrashing due to Inline Handlers & Re-evaluating DivIcons
**Learning:** In react-leaflet, re-creating objects directly in the map render loop, such as inline `eventHandlers={{ click: handler }}` on `<Marker>` elements and dynamically calling Leaflet factory functions like `L.divIcon` without caching, causes unnecessary, potentially massive DOM thrashing, especially when markers are filtered/searched rapidly.
**Action:** Extract react-leaflet elements inside lists to their own `<MemoizedComponent>` wrapped with `React.memo()`, pass primitive-evaluated stable references as properties where possible (e.g. `onClick={setSelected}` passing bare state setter directly is perfectly stable natively), and cache costly factory-created mapping elements like `L.divIcon` using an external `Map` indexed by a composite state-key parameter string to prevent recreating DOM nodes.
