## 2024-06-26 - React-Leaflet object references
**Learning:** In react-leaflet, inline objects and unmemoized Leaflet creations like `L.divIcon()` or `pathOptions` passed to components like `<Marker>` or `<Polyline>` can cause severe DOM thrashing. When the parent component re-renders (e.g., when the `selected` attraction state changes), react-leaflet detects "new" icon or option references. It then removes the existing map layers and re-adds them from scratch.
**Action:** Always wrap Leaflet config objects in `useMemo` or move them outside the component as static constants. Similarly, always ensure custom `L.DivIcon`s created via functions are cached using a `Map` or similar strategy to preserve stable object references across re-renders. Use `memo` effectively for Marker components mapped from lists, keeping positions and event handlers memoized inside.
