## 2024-05-24 - React-Leaflet Render Loop Optimization
**Learning:** Passing an inline object to the `eventHandlers` prop of a React-Leaflet `Marker` component (e.g., `eventHandlers={{ click: () => setSelected(a) }}`) inside a map loop causes a new object reference to be created on every render. Furthermore, calling `makePin` directly in the loop recreates the `L.DivIcon` instance each time. This forces React-Leaflet to re-attach event listeners and recreate marker icons for every single attraction on the map during any state update (e.g., typing in the search bar), significantly impacting main thread performance.
**Action:** Extract the `Marker` into a separate, memoized React component (e.g., `MemoizedMarker`). Pass only stable primitives (like the attraction's ID or pre-calculated primitive state) and stable function references (like the raw `setSelected` setter) to this memoized component. Cache the generated `L.DivIcon` instances based on their dynamic parameters to avoid instantiating new Leaflet objects unnecessarily.
