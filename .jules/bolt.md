## 2024-05-24 - React-Leaflet Loop Optimization
**Learning:** In react-leaflet, defining objects and functions inline inside a mapped loop (e.g., `icon={makePin(...)}` or `eventHandlers={{ click: handler }}`) causes new object and function references to be created on every render. This leads to unnecessary and potentially expensive DOM updates since react-leaflet components rely on reference equality to determine if props have changed. Recreating Leaflet icons dynamically is particularly costly.
**Action:** Extract Leaflet elements inside loops into memoized components. Memoize props, like `eventHandlers`, inside the extracted component and use an external `Map` to cache dynamic properties (like `L.divIcon` instances based on their parameters) to prevent unnecessary re-creations and re-renders.
