## 2024-08-20 - Memoizing L.divIcon in react-leaflet render loop
**Learning:** In react-leaflet, passing inline objects or functions to the `eventHandlers` prop (e.g., `eventHandlers={{ click: handler }}`) inside loops creates new object references on every render, leading to unnecessary DOM updates. Also, recreating `L.divIcon` objects dynamically in every render frame (e.g., in a `.map` loop mapping locations to markers) creates excessive memory churn and potential DOM thrashing. An effective way to cache dynamically generated objects (like `L.divIcon` for react-leaflet markers) that depend on variable arguments inside render loops is to use an external `Map` to store and retrieve instances by a stringified key.
**Action:** Extract the `L.divIcon` generation to a caching mechanism utilizing a `Map` that stores previously generated icons by stringifying their arguments as keys.
