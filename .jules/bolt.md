## 2024-05-24 - React-Leaflet Marker Re-renders
**Learning:** Using `makePin()` inside the render loop of `mapAttractions.map` creates a new `L.divIcon` instance on every render. Combined with passing an inline object/function to `eventHandlers={{ click: ... }}`, this causes React-Leaflet to destroy and recreate the underlying DOM element for each marker on every re-render of `<App />`.
**Action:** Extract the Leaflet element (like `<Marker>`) into its own memoized component (`memo`), or at least use a `Map` to cache `L.divIcon` instances by a key (e.g., `isTrip-step-color`) to prevent thrashing, and use a stable `useCallback` for the click handler. Or as memory suggests, an external Map caching the icons works well. Let's do the Map caching and memoize a `MapMarker` component.
