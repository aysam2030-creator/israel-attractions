## 2026-07-17 - Cached dynamic Leaflet divIcon objects to prevent memory thrashing\n**Learning:** Instantiating new `L.divIcon` objects dynamically inside render loops creates massive DOM thrashing and performance degradation in react-leaflet. The library expects stable references to these icon objects.\n**Action:** Use an external `Map` cache indexed by the properties (e.g., color, state) to memoize dynamically generated Leaflet map icons across re-renders to significantly improve map interaction performance.
