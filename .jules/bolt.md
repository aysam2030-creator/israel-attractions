## 2025-02-28 - React-Leaflet Map Marker Virtual DOM Thrashing Optimization
**Learning:** In React-Leaflet, passing inline callback functions (`eventHandlers={{ click: () => setSelected(a) }}`) directly inside `<Marker>` components within a large loop forces React to create new function references on every render. This completely breaks Leaflet's internal virtualization and forces expensive re-evaluations of the underlying `L.Marker` and `L.divIcon` objects, even when the underlying data (`a.lat`, `a.lng`) hasn't changed.
**Action:** Always extract inline Leaflet `<Marker>` elements into their own explicit `React.memo`-wrapped components (e.g., `<MapMarker>`). Pass stable state setter functions (like `setSelected`) and primitive props (`color`, `step`, `isTrip`) directly to the extracted component to ensure `React.memo` correctly bails out of rendering via shallow comparison. Additionally, implement an external `Map`-based cache for dynamically generated objects like `L.divIcon` that depend on variable arguments inside render loops to prevent excessive memory allocation.
