## 2024-05-18 - [Optimized Marker Map Rendering in react-leaflet]
**Learning:** Rendering complex React components or dynamically generated objects inside loops, particularly mapping elements like `<Marker>` in `react-leaflet`, often creates unnecessary new object references and leads to excessive DOM updates/bailing issues, hurting performance on maps with many markers. Passing inline objects or functions to the eventHandlers prop inside the loop is a major anti-pattern.
**Action:** Always extract the repeated UI element (like the `<Marker>`) into its own functional component, memoize it via `React.memo()`, and pass stable references for any callback or complex objects to maximize bailout efficiency. Use an external cache (e.g. `Map`) for dynamically generated icons instead of inline functions inside render.
