## 2024-09-12 - Map Marker Re-render Bottleneck in react-leaflet
**Learning:** Passing an inline object directly to `react-leaflet` components (like `eventHandlers={{ click: () => setSelected(a) }}` inside `<Marker>`) creates a new reference on every react render cycle. This causes react-leaflet to continuously unbind and rebind internal Leaflet event listeners, leading to huge DOM thrashing and CPU overhead on large data lists, especially when combined with frequent un-cached `L.divIcon()` calls.
**Action:** Always extract react-leaflet components inside loops into their own `memo()`-ized React components. Pass stable references or simple primitives to them, and always use an external cache map for `L.divIcon` instances based on a string key rather than instantiating them dynamically during render loops.
