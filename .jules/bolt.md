## 2024-05-18 - React-Leaflet Marker Memoization Bottleneck
**Learning:** In react-leaflet, mapping over large arrays to render `<Marker>` components inline with dynamically generated `icon` objects (like `L.divIcon`) and inline `eventHandlers` causes massive main-thread lag. React-Leaflet aggressively rebuilds its internal DOM layers and listeners on every parent state change because these object references are constantly destroyed and recreated.
**Action:** Always extract Leaflet elements inside loops into their own `React.memo` wrapped components. Ensure the parent passes primitive evaluated props (e.g., `tripIds.includes(id)` instead of the full array), use `useMemo` for any objects passed to Leaflet, and cache Leaflet objects like `L.divIcon` using an external `Map` bounded by a strict stringified key.
